========================================
  YONCHEN 网站图片说明
========================================

只需把对应图片放到指定文件夹即可，网站会自动显示。

📁 文件夹结构：
images/
  ├── products/          ← 产品图
  ├── hero/              ← 首页大图
  └── factory/           ← 工厂照片

========================================
📷 需要准备的图片清单
========================================

【产品图 — images/products/】
  ✅ cube-ice.jpg        方块冰机器实拍（建议尺寸：800×600px）
  ✅ flake-ice.jpg       片冰机器实拍
  ✅ crescent-ice.jpg    月牙冰机器实拍
  ✅ granular-ice.jpg    颗粒冰机器实拍

【首页大图 — images/hero/】
  ✅ hero-machine.jpg    主打机型高清图（建议尺寸：800×600px）

【工厂照片 — images/factory/】
  ✅ factory-workshop.jpg  工厂车间/生产线实拍（建议尺寸：800×600px）

========================================
📝 图片要求
========================================
- 格式：JPG 或 PNG（推荐 JPG，文件小加载快）
- 宽高比：4:3（横版照片）
- 分辨率：至少 800×600，越大越清晰
- 内容建议：
    产品图 → 白色/浅灰背景，机器正面或45度角
    工厂图 → 干净整洁的生产线或车间全景
    首页图 → 最畅销机型，构图精美

========================================
🚀 使用方法
========================================
1. 把图片按上面的文件名保存
2. 拖到对应的文件夹里
3. 刷新浏览器页面即可看到效果

没放图片时，网站会自动显示临时占位图，不影响浏览。
