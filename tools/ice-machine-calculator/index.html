How the number is built

The calculator follows the same method as our sizing guide, in five steps: estimate daily consumption, add 20% for peaks, derate the machine for ambient temperature, then pick the smallest model that clears the figure.

  • Consumption — restaurant 0.5–1.0 kg per cover per service; café 0.2–0.3 kg per iced drink; bar 0.8–1.2 kg per cover; hotel 0.5 kg per cover plus display ice; display counters 1.5–2× bed volume per shift.
  • Peak allowance — a flat 20% on top, because a normal day is not your design day.
  • Ambient derating — the selected factor is applied to the machine's output, not to your demand, which is why the recommended capacity goes up in a hot room rather than the ice requirement going down.
These are planning figures, not guarantees. A week of measured consumption beats any table — if you have the number, use the "I know my daily requirement" option and skip the estimate.
Questions

About the calculation

Why does the recommendation go up when the room is hot?

A machine rated at 200 kg/24h produces less than that at 40 °C ambient. The calculator derates the machine's output, so the recommended model has to be larger to deliver the same ice. This is the most common sizing mistake we see.

Does bin size matter as much as daily output?

It matters differently. Daily output answers "can it keep up"; bin size answers "can it survive a rush". A venue with a short, intense peak needs a larger bin even if the daily total looks sufficient.

Can I use this for a project specification?

Use it to shortlist, not to specify. For a tender or a project you need the actual model datasheet, the electrical supply and the installation conditions — send those and we will confirm in writing.
